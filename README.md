# 선택과목 변경 관리 (천안신당고 교육과정부)

https://joyeonguk.github.io/sindang-subject-change/

교사 전용 페이지입니다. 과목선택 DB 구글 시트를 직접 불러와 변경 신청서를 작성·인쇄하고, 보호자 서명본을 받은 학생만 시트에 반영합니다.

## 처리 흐름
1. **작성**: 반을 고르고 이름으로 학생을 찾아 변경 과목·사유를 입력합니다.
2. **처리중**: 확인서[양식1]와 신청서[양식2]를 인쇄(또는 PDF 저장)하면 「처리중」이 됩니다.
3. **접수완료**: 학생·보호자·담임 서명본을 받아 「서명본 접수 완료」를 누르면, DB 탭의 그 학생 과목 칸이 바뀝니다.

모든 기록은 같은 스프레드시트의 「변경신청」 탭에 남습니다(기존 과목, 변경 후 과목, 출력·접수 일시).

## 학년별 시트
| 대상 | 탭 | 1학기 | 2학기 |
|---|---|---|---|
| 현 1학년 → 2학년 과정 | 천안신당고등학교 과목선택 DB | B~G (6) | H~M (6) |
| 현 2학년 → 3학년 과정 | 2학년 과목선택 | B~H (7) | I~O (7) |

## 처음 한 번: 연결 준비
페이지의 **설정** 탭에 단계별 안내가 있습니다.
1. Google Cloud에서 프로젝트를 만들고 Google Sheets API를 사용으로 바꿉니다.
2. OAuth 동의 화면을 만들고, 테스트 사용자에 선생님 계정을 넣습니다.
3. 웹 애플리케이션용 OAuth 클라이언트 ID를 만듭니다. 승인된 자바스크립트 원본은 `https://joyeonguk.github.io`입니다.
4. 클라이언트 ID를 `config.js`(또는 설정 탭)에 넣습니다. 시트 주소는 설정 탭에 넣습니다.
5. 「Google 시트 연결」을 누르고 시트 소유자 계정으로 로그인합니다.

학생 데이터와 시트 주소는 GitHub에 올라가지 않습니다. 시트 주소는 각 컴퓨터의 브라우저에만 저장되고, 데이터는 선생님 계정 권한으로 시트에서 바로 읽고 씁니다.

클라이언트 ID가 없거나 주소 뒤에 `?demo`를 붙이면 예시 데이터로 모든 기능을 미리 볼 수 있습니다(저장되지 않음).
