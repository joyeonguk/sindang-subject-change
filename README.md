# 2027 선택과목 변경 신청 (천안신당고)

- 미리보기(예시 데이터): https://joyeonguk.github.io/sindang-subject-change/
- 실제 운영용 코드: `apps-script/` 폴더 (Google Apps Script 웹앱)

# 2027 선택과목 변경 신청 페이지: 설치 안내

## 파일
- `Code.gs`: Apps Script 서버 코드(본인 확인, 저장, 교사 기능)
- `App.html`: 학생 화면과 교사 화면이 함께 들어 있는 HTML 파일

## 배포 순서 (10분)
1. https://script.google.com 에서 **새 프로젝트**를 만듭니다. 이름은 예를 들어 `2027 선택과목 변경 신청`으로 정합니다.
2. 기본으로 있는 `Code.gs` 내용을 지우고 `apps-script/Code.gs`를 붙여 넣습니다.
3. 파일 추가(+) → **HTML**을 고르고 이름을 `App`으로 정한 뒤 `apps-script/App.html` 내용을 붙여 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**(학생이 구글 로그인 없이 접속할 수 있게)
5. 처음 배포할 때 권한 승인 창이 뜨면 허용합니다(스프레드시트 읽기·쓰기, 드라이브에 파일 만들기).
6. 웹 앱 주소 맨 뒤에 `?page=teacher`를 붙여 교사 화면을 엽니다. 「저장소 만들기」에서 아래 항목을 입력합니다.
   - 교사 비밀번호
   - 과목선택 DB 주소: 「천안신당고등학교 과목선택 1학년 DB」 스프레드시트의 주소
   - 시트 이름: `천안신당고등학교 과목선택 DB`
   - 신청 기간: 2026-12-07 ~ 2026-12-23
   → 내 드라이브에 「2027 선택과목 변경 신청 저장소」 스프레드시트가 자동으로 만들어집니다.
7. 학생에게는 `?page=teacher`를 뺀 주소만 안내합니다.

## 주소 두 개
| 용도 | 주소 |
|---|---|
| 학생 | `https://script.google.com/macros/s/…/exec` |
| 교사 | `https://script.google.com/macros/s/…/exec?page=teacher` |

## 확인할 점
- 학생은 **현재 학번(1학년, 예: 10106)**으로 로그인합니다. DB A열이 「10106 김민호」 형식이기 때문입니다.
- 과목선택 DB는 **읽기만** 하고 고치지 않습니다. 승인된 변경을 DB나 나이스에 반영하는 일은 담당자가 직접 합니다.
- 학생이 「접수」 상태일 때는 스스로 수정·취소할 수 있습니다. 교사가 「상담중」 이상으로 바꾸면 학생은 더 이상 수정할 수 없습니다.
- 교사 메모는 학생이 로그인했을 때 보입니다(상담 일정 안내 등에 활용).
- 신청 가능 과목 목록은 `Code.gs` 맨 위 `SUBJECTS`에 안내문 목록대로 들어 있습니다. 과목이 바뀌면 이 목록만 고치면 됩니다.
- 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다(주소는 그대로).
