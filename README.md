# 선택과목 변경 관리 (천안신당고 교육과정부)

https://joyeonguk.github.io/sindang-subject-change/

교사 전용 페이지입니다. 1학년·2학년 과목선택 시트를 불러와 변경 신청서를 작성·인쇄하고, 보호자 서명본을 받은 학생만 시트에 반영합니다.

## 들어가기
- 「1학년 담임교사 / 2학년 담임교사」를 고르고 **성함**과 **교사 공용 비밀번호**를 입력합니다.
- 같은 기기에서는 다음부터 바로 들어갑니다(설정 → 이 기기에서 나가기로 지울 수 있음).

## 처리 흐름
1. **작성**: 반을 고르고 이름으로 학생을 찾아 변경 과목과 사유를 입력합니다.
2. **처리중**: 확인서[양식1]와 신청서[양식2]를 인쇄(또는 PDF 저장)합니다.
3. **접수완료**: 서명본을 받아 「서명본 접수 완료」를 누르면 그 학생의 과목 칸이 시트에서 바뀝니다.

각 학년 스프레드시트의 「변경신청」 탭에 모든 기록이 남습니다. 기존 과목, 변경 후 과목, 일시, **작성·출력·접수 선생님 성함**이 함께 기록됩니다.

## 학년별 시트
| 대상 | 탭 | 1학기 | 2학기 |
|---|---|---|---|
| 현 1학년 → 2학년 과정 | 천안신당고등학교 과목선택 DB | B~G (6) | H~M (6) |
| 현 2학년 → 3학년 과정 | 2학년 과목선택 | B~H (7) | I~O (7) |

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 교사 화면 (GitHub Pages) |
| `config.js` | 연결 통로 주소 `API_URL` (비어 있으면 예시 데이터로 동작) |
| `apps-script/Code.gs` | 연결 통로. 비밀번호 확인, 시트 읽기·쓰기. 시트 ID와 비밀번호는 Apps Script 안에만 넣습니다 |

학생 데이터, 시트 주소, 비밀번호는 GitHub에 올라가지 않습니다.

## 연결 통로 설치 (관리 선생님, 처음 한 번)
1. https://script.google.com 에서 **새 프로젝트**를 만들고 `Code.gs` 내용을 붙여 넣습니다. 맨 위 설정(비밀번호, 1·2학년 시트 ID)을 채웁니다.
2. **배포 → 새 배포 → 웹 앱**을 고릅니다. 실행은 **나**, 액세스는 **모든 사용자**로 정합니다.
3. 권한을 승인하고, 나온 `…/exec` 주소를 `config.js`의 `API_URL`에 넣습니다.

코드나 비밀번호를 고친 뒤에는 **배포 관리 → 연필 → 버전: 새 버전 → 배포**를 합니다. 주소는 그대로 유지됩니다.

주소 뒤에 `?demo`를 붙이면 예시 데이터로 모든 기능을 미리 볼 수 있습니다(저장되지 않음).
